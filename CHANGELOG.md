# Changelog

## Interface and output update

- Cyber-themed dashboard with live lookup spinner, elapsed time, active module and session counters.
- Plain-language module explanations, selected findings and `d` for full technical details without another request.
- Focused VirusTotal detection summaries and OTX association summaries.
- Compact tables, literal text rendering and optional externally configured local portrait support. No portrait artwork is distributed.
- 73 automated tests pass.

## 1.0.0 — Standalone edition

- New package with 22 guided indicator, DNS, website and offline JWT capabilities.
- Four-option home menu, contextual guidance and labeled result tables.
- Existing private environment configuration supported without copying credentials.
- Bounded requests, explicit redirect handling and credential-safe diagnostics.
- 71 automated tests; initial GitHub matrix passed on Python 3.10, 3.12 and 3.13.
- Added migration reference, security and contribution guidance, and a `threathawk` command alias during the completeness audit.
