# Provider interface references

Interface documentation consulted for this build; no provider sample code is bundled:

- Shodan host lookup: https://developer.shodan.io/api
- Censys host endpoint: https://docs.censys.com/reference/v3-globaldata-asset-host
- Censys PAT authentication: https://docs.censys.com/reference/get-started
- VirusTotal IP reports and indicator handling: https://docs.virustotal.com/reference/ip-info
- OTX API entry point: https://otx.alienvault.com/api
- OTX provider-maintained interface reference: https://github.com/AlienVault-OTX/OTX-Python-SDK
- Google DNS JSON endpoint: https://developers.google.com/speed/public-dns/docs/doh/json
- Internet Archive CDX: https://github.com/internetarchive/wayback/tree/master/wayback-cdx-server
- ipwho.is: https://ipwhois.io/documentation
- Certificate transparency service: https://crt.sh/ (JSON interface; availability is not guaranteed)

Provider subscriptions, quotas, retention and terms are independent of this application's license.
